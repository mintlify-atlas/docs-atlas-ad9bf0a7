# Platform Features

CALMA is a comprehensive healthcare employment platform designed specifically for connecting elderly care professionals (Aspirantes) with employers (Contratantes). This page covers all major features organized by user role and functionality.

## Dual-Module Architecture

CALMA operates with two distinct user experiences:

<CardGroup cols={2}>
  <Card title="Aspirante Module" icon="user" color="#3b82f6">
    **For Job Seekers**
    
    Healthcare professionals looking for employment opportunities in elderly care.
    
    - Browse job listings
    - Manage digital CV
    - Apply to positions
    - Track applications
    - Communicate with employers
  </Card>
  
  <Card title="Contratante Module" icon="briefcase" color="#10b981">
    **For Employers**
    
    Families and healthcare facilities seeking qualified care professionals.
    
    - Post job opportunities
    - Register patients
    - Review applications
    - Manage patient records
    - Rate care professionals
  </Card>
</CardGroup>

## Core Features by Category

### 📄 CV Management (Aspirantes)

Comprehensive digital curriculum vitae system with multi-step creation:

<Steps>
  <Step title="Basic CV Information">
    Primary CV form located at `/moduloAspirante/cv`:
    
    ```jsx src/components/ModuloAspirante/CV/cv.jsx
    // Core CV fields managed through CVForm component
    const [formulario, setFormulario] = useState({
      estado: true,
      experiencia: '',           // Work experience in elderly care
      zona_trabajo: '',          // Preferred work zones
      idiomas: '',               // Languages spoken
      informacion_opcional: '',  // Additional information
      fecha_solicitud: new Date().toISOString()
    });
    ```
    
    <Note>
      The CV is **required** before accessing any Aspirante features. The `RequireCV` component enforces this requirement.
    </Note>
  </Step>

  <Step title="Professional Certifications">
    Add healthcare certifications at `/cv/:idCV/certificados`:
    - Certificate title and issuing organization
    - Issue date and expiration date
    - Document upload support
    - Multiple certifications per profile
  </Step>

  <Step title="Skills & Abilities">
    Define your skillset at `/cv/:idCV/habilidades`:
    - Medical care skills
    - Personal care abilities
    - Special needs experience
    - Emergency response training
  </Step>

  <Step title="Recommendations">
    Collect professional references at `/cv/:idCV/recomendaciones`:
    - Reference contact information
    - Professional relationship
    - Recommendation text
    - Verification status
  </Step>

  <Step title="Availability Schedule">
    Set your working availability at `/cv/:idCV/disponibilidad`:
    - Daily availability patterns
    - Preferred shift times
    - Weekend and holiday availability
    - Start date preferences
  </Step>
</Steps>

**CV Viewing Options:**
- Complete view: `/ver-cv/:idCV` (public)
- Aspirante edit view: `/cv/:idCV/edit`
- Contratante applicant view: `/cv-aspirante/:idAspirante`
- CV with ratings: Includes aggregated rating display from completed jobs

### 📬 Application System

#### Aspirante: Application Tracking

Manage your job applications at `/moduloAspirante/postulaciones/:userId`:

```jsx src/components/ModuloAspirante/PostulacionesAspirante/
// Track application status through the hiring pipeline
```

**Application States:**
1. **Pendiente** (Pending): Application submitted, awaiting review
2. **Aceptada** (Accepted): Employer accepted your application
3. **Rechazada** (Rejected): Application was not selected
4. **En Proceso** (In Process): Interview or evaluation phase
5. **Completada** (Completed): Job finished, eligible for rating

**Application Features:**
- Status change notifications
- Timeline of application progress
- Direct communication with employer
- Access to patient details (when accepted)
- Withdraw application option

#### Contratante: Application Review

Review applicants at `/postulaciones/:userId` and `/detalles-trabajo/:idRealizar`:

```jsx src/components/ModuloContratante/Postulaciones/Postulaciones.jsx
// Review candidate CVs and make hiring decisions
```

**Review Features:**
- View complete candidate CVs
- See applicant ratings from previous jobs
- Review certifications and recommendations
- Accept or reject applications
- Request additional information
- Schedule video interviews
- Shortlist candidates for comparison

### 💬 Real-Time Chat System

WebSocket-based messaging between Aspirantes and Contratantes:

```jsx src/App.jsx
// Chat component using STOMP.js over WebSocket
function App({
  nombrePropio = "1",           // Current user ID
  destinatarioProp = "2",       // Recipient ID
  nombreUsuarioActual = null,   // Current user display name
  nombreDestinatario = null,    // Recipient display name
  datosDestinatario = null      // Full recipient data object
}) {
  // WebSocket connection setup
  const cliente = new Client({
    brokerURL: "ws://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/ws",
    reconnectDelay: 5000,
    heartbeatIncoming: 4000,
    heartbeatOutgoing: 4000,
  });
```

**Chat Features:**
- Real-time message delivery
- Message history persistence
- Read receipts and delivery status
- Typing indicators
- Connection status display
- Automatic reconnection on disconnect
- Message notifications when not actively in chat
- Job context display (shows which position the conversation relates to)

**Technical Implementation:**
- STOMP protocol over WebSocket
- Subscription to conversation channels: `/tema/conversacion/{userId1}-{userId2}`
- Personal notifications: `/tema/notificacion/{userId}`
- Messages sent to: `/app/envio`
- Unique conversation channels based on sorted user IDs (prevents duplicate channels)

**Chat Access:**
- **Aspirantes**: Can chat with employers who accepted their application
- **Contratantes**: Can chat with applicants they've accepted or shortlisted
- Chat panel accessible from header in both modules
- Search and filter conversation partners

- Privacy controls and access restrictions

#### Patient Record Sharing

When an Aspirante's application is accepted:
- They gain **read-only** access to patient medical records
- Accessible at `/moduloAspirante/ficha-paciente/:idPaciente`
- View at `/verfcihaaceptada` component
- Includes all medical history except private notes

### ⭐ Rating & Review System

Two-way rating system after job completion:

#### Contratantes Rate Aspirantes

Rate care workers at `/Calificacion/calificacion`:

```jsx src/components/Calificacion/calificacion.jsx
// Rating form for completed jobs
```

**Rating Categories:**
- **Professionalism**: Punctuality, appearance, attitude
- **Care Quality**: Attention to patient needs, compassion
- **Communication**: With patient, family, and healthcare team
- **Technical Skills**: Medical care competency
- **Reliability**: Consistency and dependability

**Rating Features:**
- 1-5 star rating scale
- Written review comments
- Anonymous or public rating option
- Dispute resolution process
- Rating appears on Aspirante CV

#### Aspirantes Rate Employers

Provide feedback on completed positions:

**Rating Categories:**
- Work environment and conditions
- Compensation and payment timeliness
- Job description accuracy
- Communication and support
- Would work with them again?

**Access Ratings:**
- Aspirante ratings visible at: `/aspirante/:aspiranteId/calificaciones`
- All ratings viewable: `/moduloAspirante/Calificaciones/TodasLasCalificaciones`
- Ratings shown on CV: Component at `src/components/ModuloAspirante/CV/CalificacionesCV/`

## Technical Features

### State Management

CALMA uses React hooks for state management:
- `useState` and `useEffect` for local component state
- `useContext` potential for global state (not currently implemented)
- `localStorage` for authentication persistence
- `sessionStorage` for temporary UI state

### API Integration

All API calls organized in service files (`src/servicios/`):

<CodeGroup>
```javascript src/servicios/cvService.js
// CV-related API calls
export const createCV = async (cvData, aspiranteId) => { ... }
export const getCVById = async (idCV) => { ... }
export const updateCV = async (idCV, cvData) => { ... }
export const getCVByAspiranteId = async (aspiranteId) => { ... }
export const checkIfAspiranteHasCV = async (aspiranteId) => { ... }
```

```javascript API Service Pattern
// Consistent axios-based API service pattern
import axios from 'axios';

const BASE_URL = 'http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090';

export const serviceMethod = async (params) => {
  try {
    const response = await axios.get(`${BASE_URL}/api/endpoint`, {
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${localStorage.getItem('token')}`
      }
    });
    return response.data;
  } catch (error) {
    console.error('Service error:', error);
    throw error;
  }
};
```
</CodeGroup>

### WebSocket Architecture

**STOMP over WebSocket:**
```javascript
import { Client } from '@stomp/stompjs';

// Client setup

  brokerURL: 'ws://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/ws',

// Subscribe to topics
```
