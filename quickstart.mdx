# Quickstart Guide

Get the CALMA healthcare employment platform running locally in just a few minutes. This guide covers installation, setup, and your first steps with the application.

## Prerequisites

Before you begin, ensure you have the following installed:

- **Node.js** (version 18 or higher)
- **npm** (comes with Node.js)
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- Git (for cloning the repository)

## Installation

<Steps>
  <Step title="Clone the Repository">
    Clone the CALMA repository to your local machine:
    
    ```bash
    git clone <repository-url>
    cd calma
    ```
  </Step>

  <Step title="Install Dependencies">
    Install all required npm packages:
    
    ```bash
    npm install
    ```
    
    This will install all dependencies listed in `package.json`, including:
    - React 19 (UI framework)
    - React Router 6.30 (routing)
    - Axios 1.10 (HTTP client)
    - STOMP.js 7.0 (WebSocket client)
    - Firebase 11.10 (authentication & storage)
    - Vite 6.1 (build tool)
  </Step>

  <Step title="Configure Environment">
    The application connects to the backend API by default. The API endpoint is:
    
    ```
    http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090
    ```
    
    <Note>
      Environment configuration is minimal - the backend URL is hardcoded in service files. For production, consider moving this to environment variables.
    </Note>
  </Step>

  <Step title="Start Development Server">
    Launch the Vite development server:
    
    ```bash
    npm run dev
    ```
    
    The application will start on `http://localhost:5173` (or the next available port).
    
    <Tip>
      Vite provides instant hot module replacement (HMR) - changes you make will appear immediately without full page reloads.
    </Tip>
  </Step>
</Steps>

## First Steps: Choosing Your Role

CALMA has two distinct user modules. Choose the path that matches your needs:

### For Job Seekers (Aspirantes)

<Steps>
  <Step title="Register as Aspirante">
    Navigate to `/registro` and create an account with the "Aspirante" role.
    
    ```jsx src/components/Registro/registro.jsx
    // Registration allows selection between Aspirante and Contratante roles
    ```
  </Step>

  <Step title="Create Your CV">
    Upon first login, you'll be prompted to create your curriculum vitae. This is **required** before accessing job listings.
    
    The CV form is located at `/moduloAspirante/cv` and includes:
    - Work experience in elderly care
    - Preferred work zones
    - Languages spoken
    - Optional additional information
    
    <Note>
      The `RequireCV` component guards all Aspirante routes - you must complete your CV to access features.
    </Note>
  </Step>

  <Step title="Browse Job Listings">
    Access your dashboard at `/moduloAspirante` to:
    - View available job postings
    - Apply to positions with one click
    - Track your application status
    - Receive notifications about new opportunities
  </Step>

  <Step title="Communicate with Employers">
    Once your application is accepted:
    - Chat in real-time via WebSocket (STOMP protocol)
    - Schedule and conduct video interviews
    - View patient information for accepted positions
  </Step>
</Steps>

### For Employers (Contratantes)

<Steps>
  <Step title="Register as Contratante">
    Create an account with the "Contratante" role at `/registro`.
  </Step>

  <Step title="Register Patients">
    Before posting jobs, register the patients who need care:
    
    Navigate to `/moduloContratante/registropaciente` to add:
    - Patient personal information
    - Medical history
    - Care requirements
  </Step>

  <Step title="Create Job Postings">
    Post new job opportunities at `/moduloContratante/formularioPublicacion`:
    
    ```jsx src/components/ModuloContratante/FormularioPublicacion/
    // Create detailed job postings linked to patient records
    ```
    
    Include:
    - Job title and description
    - Required skills and experience
    - Work schedule and location
    - Compensation details
    - Associated patient
  </Step>

  <Step title="Review Applications">
    Manage applications at `/postulaciones/:userId`:
    - View candidate CVs
    - Accept or reject applications
    - Initiate communication with selected candidates
    - Rate completed work
  </Step>
</Steps>

## Understanding the Routing Structure

CALMA uses React Router with role-specific paths:

```jsx src/main.jsx
// Public routes
<Route path="/" element={<Inicio />} />
<Route path="/login" element={<Login />} />
<Route path="/registro" element={<Registro />} />

// Protected Aspirante routes (require CV)
<Route path="/moduloAspirante/*" element={
  <RequireCV><ModuloAspirante /></RequireCV>
} />

// Contratante routes
<Route path="/moduloContratante/*" element={<ModuloContratante />} />
```

## Real-Time Communication Setup

CALMA uses WebSocket connections for chat and video calls:

### Chat Connection

The chat component (`src/App.jsx`) connects to:

```javascript src/App.jsx:259-265
const cliente = new Client({
  brokerURL: "ws://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/ws",
  reconnectDelay: 5000,
  heartbeatIncoming: 4000,
  heartbeatOutgoing: 4000,
});
```

- Messages are sent to `/app/envio` destination
- Users subscribe to `/tema/conversacion/{userId1}-{userId2}` channels
- Personal notifications arrive on `/tema/notificacion/{userId}`

### Video Calls

Video calling uses WebRTC with STOMP signaling:

```javascript src/videollamada.jsx:33-34
const socket = new SockJS("http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/ws");
stompClient = Stomp.over(socket);
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Port 5173 is already in use">
    Vite will automatically try the next available port. Check the terminal output for the actual port being used.
    
    Alternatively, specify a custom port:
    ```bash
    npm run dev -- --port 3000
    ```
  </Accordion>

  <Accordion title="WebSocket connection fails">
    Ensure the backend server is running and accessible. Check:
    - Network connectivity to the backend URL
    - CORS configuration allows your origin
    - WebSocket ports are not blocked by firewall
  </Accordion>

  <Accordion title="CV creation fails or redirects incorrectly">
    The CV system checks if you already have a CV before creating a new one. Clear localStorage if you're testing:
    ```javascript
    localStorage.removeItem('userData');
    ```
  </Accordion>

  <Accordion title="Firebase configuration missing">
    Firebase is used for authentication and storage. Ensure Firebase credentials are properly configured in your environment.
  </Accordion>
</AccordionGroup>

<Warning>
  **Production Deployment**: This quickstart is for local development only. For production deployment, run `npm run build` and serve the `/dist` folder through a web server with proper SSL/TLS certificates.
</Warning>
