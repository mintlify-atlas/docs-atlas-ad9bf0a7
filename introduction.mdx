## Welcome to CALMA

CALMA is a comprehensive healthcare employment platform designed to bridge the gap between healthcare professionals seeking meaningful work and employers looking for qualified talent. Our platform streamlines the entire employment journey, from CV creation to real-time communication and patient care management.

## What is CALMA?

CALMA (Conectando Aspirantes con el Mercado Laboral) is a full-featured SaaS platform built with React that provides:

- **Dual User Roles**: Separate interfaces for job seekers (Aspirantes) and employers (Contratantes)
- **Comprehensive CV Management**: Build professional CVs with certificates, recommendations, skills, and availability
- **Smart Job Matching**: Advanced filtering and search capabilities to connect the right talent with the right opportunities
- **Real-Time Communication**: Built-in chat and video calling for seamless interaction between employers and candidates
- **Patient Record Management**: Integrated system for managing patient health records (fichas)
- **Rating System**: Transparent qualification system for both job seekers and employers

## Technology Stack

CALMA is built with modern web technologies:

- **Frontend**: React 19 with React Router for navigation
- **State Management**: React hooks and context
- **Real-Time Communication**: STOMP.js over WebSocket
- **HTTP Client**: Axios for API integration
- **UI Components**: Framer Motion for animations, Lucide React for icons
- **Authentication**: Firebase integration
- **Styling**: CSS with custom themes
- **Build Tool**: Vite
