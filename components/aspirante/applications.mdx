# PostulacionesAspirante Component

Manages and displays all job applications submitted by an aspirant, including status tracking and patient information access.

## Component Location

`src/components/ModuloAspirante/PostulacionesAspirante/PostulacionesAspirante.jsx`

## Component Structure

```javascript
const PostulacionesAspirante = () => {
  const { aspiranteId } = useParams();
  const [postulaciones, setPostulaciones] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);
  const [userId, setUserId] = useState(null);
  const [currentAspiranteId, setCurrentAspiranteId] = useState(null);
  const [chatbotAbierto, setChatbotAbierto] = useState(false);
}
```

## State Management

| State | Type | Purpose |
|-------|------|--------|
| `postulaciones` | array | List of job applications |
| `loading` | boolean | Loading state for data fetch |
| `error` | string/null | Error message if fetch fails |
| `userId` | number/null | User ID for chat functionality |
| `currentAspiranteId` | number/null | Current aspirante identifier |
| `chatbotAbierto` | boolean | Chatbot visibility state |

## Data Fetching

### Aspirante ID Resolution

```javascript
useEffect(() => {
  const userData = JSON.parse(localStorage.getItem("userData") || '{}');
  const finalAspiranteId = aspiranteId || userData?.aspiranteId;
  
  if (!finalAspiranteId) {
    setError('No se pudo identificar al aspirante');
    setLoading(false);
    return;
  }
  
  setCurrentAspiranteId(finalAspiranteId);
  obtenerUserId(finalAspiranteId);
}, [aspiranteId]);
```

### User ID Mapping

```javascript
const obtenerUserId = async (idAspirante) => {
  try {
    // Check localStorage first
    const userData = JSON.parse(localStorage.getItem('userData') || '{}');
    if (userData.usuarioId || userData.userId) {
      setUserId(userData.usuarioId || userData.userId);
      return;
    }

    // Fetch from API
    const response = await axios.get(
      `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/usuarios/buscar_aspirante/${idAspirante}`
    );
    setUserId(response.data);
  } catch (error) {
    setUserId(idAspirante); // Fallback
  }
};
```

### Fetch Applications

```javascript
const fetchData = async () => {
  try {
    setLoading(true);
    const response = await axios.get(
      `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/realizar/aspirante/${currentAspiranteId}`
    );
    
    if (response.data && Array.isArray(response.data)) {
      setPostulaciones(response.data);
    } else {
      setPostulaciones([]);
    }
  } catch (err) {
    setError('Error al cargar tus postulaciones');
  } finally {
    setLoading(false);
  }
};
```

## Date Formatting

```javascript
const formatoFecha = (fecha) => {
  if (!fecha) return 'Fecha no disponible';
  
  try {
    const options = {
      year: 'numeric',
      month: 'long',
      day: 'numeric'
    };
    return new Date(fecha).toLocaleDateString('es-ES', options);
  } catch {
    return 'Fecha inválida';
  }
};
```
