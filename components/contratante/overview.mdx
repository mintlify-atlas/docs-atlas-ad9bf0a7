## Notifications System

### Fetch Unread Notifications

```javascript
useEffect(() => {
  const fetchNoLeidas = async () => {
    if (!contratanteId) return;

    try {
      const endpoint = `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/notificaciones/contratante/noleidas/${contratanteId}`;
      const res = await axios.get(endpoint);
      setCantidadNoLeidas(res.data.length);
    } catch (error) {
      console.error("Error al cargar notificaciones:", error);
    }
  };

  fetchNoLeidas();
  
  // Dynamic intervals
  const intervalo = usuarioChat ? 3000 : 30000; // 3s if chat active, 30s otherwise
  const interval = setInterval(fetchNoLeidas, intervalo);
  
  return () => clearInterval(interval);
}, [contratanteId, usuarioChat]);
```

### Notification Types

```javascript
const getNotificationType = (descripcion) => {
  const desc = descripcion.toLowerCase();
  
  if (desc.includes('💬') || desc.includes('nuevo mensaje')) {
    return 'info';
  }
  if (desc.includes('aceptada') || desc.includes('felicitaciones')) {
    return 'success';
  }
  if (desc.includes('rechazada') || desc.includes('lamentamos')) {
    return 'warning';
  }
  
  return 'info';
};
```

### Notification Icons

```javascript
const getNotificationIcon = (descripcion) => {
  const desc = descripcion.toLowerCase();
  
  if (desc.includes('💬') || desc.includes('nuevo mensaje')) return '💬';
  if (desc.includes('postulación')) return '👤';
  if (desc.includes('trabajo completado')) return '✅';
  
  return 'ℹ️';
};
```

```javascript
const handleAbrirPanelUsuarios = async () => {
```

## API Endpoints

| Endpoint | Method | Purpose |
|----------|--------|--------|
| `/api/usuarios/{id}` | GET | Fetch user data |
| `/api/notificaciones/contratante/noleidas/{id}` | GET | Get unread notifications |
| `/api/notificaciones/contratante/{id}` | GET | Get all notifications |
| `/api/notificaciones/contratante/marcar-leidas/{id}` | PUT | Mark as read |
| `/api/postulacion/contratista/{id}/aspirantes-para-chat` | GET | Get chat-eligible aspirants |
