## Overview

Welcome to CALMA, the healthcare employment platform designed to connect talented professionals with dignified and fair employment opportunities. As a job seeker (aspirante), you have access to powerful tools to showcase your skills, browse opportunities, and manage your applications.

<Note>
CALMA is built specifically for the healthcare industry, helping you find positions that align with your skills and aspirations.
</Note>

## Getting Started

### Creating Your Account

Before you can access job opportunities, you'll need to register as an aspirante in the system. The authentication system uses **Firebase** for secure user management.

<Steps>
  <Step title="Navigate to Registration">
    Visit the registration page and select the **Aspirante** (Job Seeker) role.
  </Step>
  
  <Step title="Provide Your Details">
    Fill in your basic information including:
    - Full name (nombres and apellidos)
    - Email address (correo)
    - Password (minimum 8 characters)
    - National ID (cédula)
    - Date of birth (fechaNacimiento)
    - Gender (genero)
  </Step>
  
  <Step title="Complete Registration">
    Upon successful registration, your data is stored in the system and you'll receive an `aspiranteId` that identifies your profile throughout the platform.
  </Step>
</Steps>

### First Login

When you log in for the first time, the system checks if you have a CV on file:

```javascript
// From Login.jsx:101-119
const handleAspiranteLogin = async (userData) => {
  const cvData = await getCVByAspiranteId(userData.aspiranteId);
  
  if (!cvData) {
    // Redirect to CV creation
    navigate('/cv/new', {
      state: { userId: userData.aspiranteId, isFirstTime: true }
    });
  } else {
    // Redirect to job seeker dashboard
    navigate('/moduloAspirante', {
      state: { userId: userData.aspiranteId, hasCV: true }
    });
  }
};
```

<Info>
If you don't have a CV yet, you'll be automatically redirected to create one. This is **required** before you can browse and apply for jobs.
</Info>

CALMA includes a real-time chat system using **WebSocket** (STOMP protocol) for instant communication with employers.

#### How Chat Works

```javascript
// From App.jsx:259-265
const cliente = new Client({
  brokerURL: "ws://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/ws",
  reconnectDelay: 5000,
  heartbeatIncoming: 4000,
  heartbeatOutgoing: 4000,
});
```

<Card title="Chat Features" icon="comments">
  - **Real-time messaging** - Instant message delivery
  - **Message history** - Access to previous conversations
  - **Connection status** - Visual indicator of connection state
  - **Message notifications** - Alerts for new messages
  - **Conversation channels** - Unique channel per employer-applicant pair
</Card>

#### Conversation Channels

Each conversation has a unique channel based on user IDs:

```javascript
// From App.jsx:112-117
const canalConversacion = useMemo(() => {
  const menor = Math.min(usuarioActual, destinatario);
  const mayor = Math.max(usuarioActual, destinatario);
  return `/tema/conversacion/${menor}-${mayor}`;
}, [usuarioActual, destinatario]);
```

<Info>
The system ensures both parties connect to the same channel by ordering the user IDs consistently.
</Info>

## Technical Details

### Data Storage

Your user information is stored in `localStorage` after successful login:

```javascript
// From Login.jsx:60
localStorage.setItem('userData', JSON.stringify(data));
```

This includes:
- `aspiranteId` - Your unique identifier
- `usuarioId` - Your user account ID
- `rol` - Your role ("aspirante")
- Profile information (nombres, apellidos, correo)

<Warning>
Do not clear your browser's localStorage while using CALMA, as this will log you out and require re-authentication.
</Warning>

### Session Management

CALMA uses a combination of:
- **localStorage** - For persistent user data across sessions
- **sessionStorage** - For temporary session-specific data
- **Firebase Authentication** - For secure credential management
