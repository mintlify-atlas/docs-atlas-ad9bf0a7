## Overview

Welcome to the employer side of CALMA, the healthcare employment platform that connects your organization with qualified, vetted professionals. As a **contratante** (employer), you have access to powerful recruitment tools to post jobs, manage applications, and communicate with candidates.

<Note>
CALMA helps you find the right talent for healthcare positions while maintaining professionalism and confidentiality throughout the hiring process.
</Note>

---

## Getting Started as an Employer

### Creating Your Employer Account

Before you can post jobs and review candidates, you'll need to register as a contratante in the system.

<Steps>
  <Step title="Navigate to Registration">
    Visit the registration page and select the **Contratante** (Employer) role.
  </Step>
  
  <Step title="Provide Business Information">
    Fill in your organization details:
    - Company name (nombreEmpresa)
    - Your name (nombres and apellidos)
    - Business email (correo)
    - Password (secure authentication)
    - National ID (cédula)
    - Phone number (telefono)
  </Step>
  
  <Step title="Complete Registration">
    After successful registration, you'll receive a `contratanteId` that serves as your unique identifier throughout the platform.
  </Step>
</Steps>

### First Login

When you log in, the system authenticates your credentials and routes you to the employer dashboard:

```javascript
// From Login.jsx:66-73
if (data.rol === 'contratante') {
  navigate('/moduloContratante', {
    state: { userId: data.contratanteId },
    replace: true
  });
}
```

<Info>
Your employer dashboard provides a comprehensive view of your hiring activities, candidate communications, and job postings.
</Info>

## Posting Job Opportunities

### Creating a Job Posting

Job postings (publicaciones de empleo) are the foundation of your recruitment efforts in CALMA.

<Steps>
  <Step title="Access Job Creation">
    Navigate to the job posting section in your dashboard.
  </Step>
  
  <Step title="Fill in Job Details">
    Provide comprehensive information about the position.
  </Step>
  
  <Step title="Set Requirements">
    Define the qualifications and skills needed.
  </Step>
  
  <Step title="Publish">
    Make your job visible to qualified candidates.
  </Step>
</Steps>

### Job Posting Fields

<AccordionGroup>
  <Accordion title="Basic Information">
    **Title** (titulo)
    - Clear, descriptive job title
    - Example: "Registered Nurse - ICU", "Home Health Aide"
    
    **Description** (descripcion)
    - Detailed overview of the role
    - Responsibilities and expectations
    - Work environment details
    
    **Salary** (salario_estimado)
    - Competitive compensation estimate
    - Transparent pricing helps attract qualified candidates
  </Accordion>
  
  <Accordion title="Work Schedule">
    **Schedule Type** (jornada)
    - Full-time (Tiempo Completo)
    - Part-time (Medio Tiempo)
    - By shift (Por Turnos)
    - Flexible (Flexible)
    
    **Shift** (turno)
    - Morning (Mañana)
    - Afternoon (Tarde)
    - Night (Noche)
    - Rotating (Rotativo)
    
    **Immediate Availability** (disponibilidad_inmediata)
    - `true` if you need someone to start right away
    - `false` if there's flexibility on start date
  </Accordion>
  
  <Accordion title="Requirements and Qualifications">
    **Requirements** (requisitos)
    - Educational requirements
    - Certifications needed
    - Years of experience
    - Language proficiency
    - Technical skills
    
    **Activities** (actividades_realizar)
    - Specific duties and tasks
    - Daily responsibilities
    - Special procedures or protocols
  </Accordion>
  
  <Accordion title="Timeline">
    **Publication Date** (fechaPublicacion)
    - Automatically set when you create the posting
    
    **Application Deadline** (fecha_limite)
    - Last date to accept applications
    - System shows formatted as: `YYYY-MM-DD`
    - Example: "2025-04-15"
  </Accordion>
  
  <Accordion title="Location">
    **Geographic Information**
    - Province (provincia)
    - Canton
    - Parish (parroquia)
    
    This helps candidates find jobs near them.
  </Accordion>
</AccordionGroup>

<Tip>
The more detailed and transparent your job posting, the more qualified candidates you'll attract.
</Tip>

### Searching for Candidates

Use the search functionality to quickly find specific candidates:

```javascript
// From moduloContratante.jsx:232-263
const handleBuscarUsuarios = async (term) => {
  const response = await axios.get(
    `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/postulacion/contratista/${contratanteId}/aspirantes-para-chat`
  );
  
  // Filter by search term
  const usuariosFiltrados = response.data.filter(usuario => {
    const nombreCompleto = `${usuario.nombres} ${usuario.apellidos}`.toLowerCase();
    const correo = usuario.correo.toLowerCase();
    const termino = term.toLowerCase();
    
    return nombreCompleto.includes(termino) || correo.includes(termino);
  });
};
```

<Tip>
Search by candidate name or email to quickly locate specific applicants in your accepted list.

## Notification Management

### Receiving Notifications

Stay informed about important events through the notification system:

```javascript
// From moduloContratante.jsx:160-192
useEffect(() => {
  const fetchNoLeidas = async () => {
    const endpoint = `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/notificaciones/contratante/noleidas/${contratanteId}`;
    const res = await axios.get(endpoint);
    setCantidadNoLeidas(res.data.length);
  };
  
  fetchNoLeidas();
  const intervalo = usuarioChat ? 3000 : 30000; // 3s if chat active, 30s otherwise
  const interval = setInterval(fetchNoLeidas, intervalo);
}, [contratanteId]);
```

<Card title="Notification Types" icon="bell">
  - **New Applications** (👤) - When candidates apply to your jobs
  - **Job Completion** (✅) - When assignments are finished
  - **New Messages** (💬) - When candidates send you messages
  - **Rating Received** (⭐) - When candidates rate completed work
  - **System Announcements** (ℹ️) - Platform updates and news

### Notification Polling

The system automatically checks for new notifications:
- **Every 3 seconds** when you have an active chat open
- **Every 30 seconds** during normal browsing

<Info>
Unread notifications are highlighted with a badge. Opening the notification panel automatically marks them as read.
</Info>

### Opening Notifications

```javascript
// From moduloContratante.jsx:277-300
const handleAbrirNotificaciones = async () => {
  // Mark all as read
  await axios.put(
    `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/notificaciones/contratante/marcar-leidas/${contratanteId}`
  );
  
  // Fetch and sort notifications
  const response = await axios.get(
    `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/notificaciones/contratante/${contratanteId}`
  );
  
  // Most recent first
  const notificacionesOrdenadas = response.data.sort((a, b) => {
    return new Date(b.fecha) - new Date(a.fecha);
  });
  
  setNotificaciones(notificacionesOrdenadas);
};
```

## Technical Information

### Session Management

Your employer session is managed through:

```javascript
// From moduloContratante.jsx:101-125
useEffect(() => {
  let contratistaId = null;
  
  if (location.state?.userId) {
    contratistaId = location.state.userId;
  } else {
    const userData = JSON.parse(localStorage.getItem('userData'));
    if (userData?.contratanteId) {
      contratistaId = userData.contratanteId;
    }
  }
  
  setUserId(contratistaId);
}, [location.state]);
```

<Info>
The system stores your `contratanteId` in localStorage for persistent authentication across browser sessions.
</Info>

### Data Loading

Employer data is loaded asynchronously:

```javascript
// From moduloContratante.jsx:127-159
const cargarDatosUsuarioActual = async (contratistaId) => {
  const response = await axios.get(
    `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/usuarios/${contratistaId}`
  );
  
  setDatosUsuarioActual({
    nombres: response.data.nombres || 'Usuario',
    apellidos: response.data.apellidos || 'Contratante',
    correo: response.data.correo,
    cedula: response.data.cedula,
    telefono: response.data.telefono
  });
};
```
