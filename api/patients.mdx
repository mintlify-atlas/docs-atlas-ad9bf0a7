## Overview

The Patients API manages patient records, including basic patient information and comprehensive medical records (fichas) with medications, allergies, interests, and conversation topics.

## Base URLs

```
http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/pacientes
http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/fichas
```

## Patients Endpoints

### Service Location

**File:** `source/src/servicios/paciente.js:1`

### GET /api/pacientes

Retrieve all patients in the system.

<CodeGroup>
```javascript Service
import { getPacientes } from './servicios/paciente';

try {
  const pacientes = await getPacientes();
  console.log('All patients:', pacientes);
} catch (error) {
  console.error('Error:', error);
}
```

```javascript Implementation
export const getPacientes = async () => {
  try {
    const response = await axios.get(
      'http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/pacientes'
    );
    return response.data;
  } catch (error) {
    console.error('Error al obtener los pacientes:', error);
    throw error;
  }
};
```

```bash cURL
curl 'http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/pacientes'
```
</CodeGroup>

### POST /api/pacientes

Create a new patient record.

```javascript
import { createPaciente } from './servicios/paciente';

const pacienteData = {
  nombres: 'Carlos',
  apellidos: 'Rodríguez',
  fecha_nacimiento: '1945-08-20',
  genero: 'Masculino',
  cedula: '1700123456',
  telefono_contacto: '0987654321',
  direccion: 'Av. Principal 123',
  contratante: { idContratante: 8 }
};

try {
  const newPaciente = await createPaciente(pacienteData);
  console.log('Patient created:', newPaciente);
} catch (error) {
  console.error('Error:', error);
}
```

### PUT /api/pacientes/{id}

Update an existing patient record.

```javascript
import { updatePaciente } from './servicios/paciente';

const updatedData = {
  telefono_contacto: '0999888777',
  direccion: 'Nueva dirección 456'
};

try {
  const updated = await updatePaciente(5, updatedData);
  console.log('Patient updated:', updated);
} catch (error) {
  console.error('Error:', error);
}
```

### DELETE /api/pacientes/{id}

Delete a patient record.

```javascript
import { deletePaciente } from './servicios/paciente';

try {
  await deletePaciente(5);
  console.log('Patient deleted successfully');
} catch (error) {
  console.error('Error:', error);
}
```

## Complete Workflow Example

### Creating a Complete Patient Record

<Steps>
  <Step title="Create Patient">
    ```javascript
    const paciente = await createPaciente({
      nombres: 'Carlos',
      apellidos: 'Rodríguez',
      fecha_nacimiento: '1945-08-20',
      genero: 'Masculino',
      cedula: '1700123456',
      telefono_contacto: '0987654321',
      contratante: { idContratante: 8 }
    });
    
    const idPaciente = paciente.id_paciente;
    ```
  </Step>
  
  <Step title="Create Ficha">
    ```javascript
    const ficha = await createFicha({
      diagnostico_me_actual: 'Hipertensión arterial',
      condiciones_fisicas: 'Movilidad reducida',
      estado_animo: 'normal',
      caidas: 'media',
      tipo_dieta: 'hiposodica',
      // ... other fields
      paciente: { id_paciente: idPaciente }
    });
    
    const idFicha = ficha.id_ficha_paciente;
    ```
  </Step>
  
  <Step title="Add Medications">
    ```javascript
    import { createMedicamento } from './servicios/medicacionService';
    ```

  </Step>

## Access Control

Patient data access is restricted based on application status:

```javascript
// Only aspirantes with accepted applications can view patient data
if (postulacion.estado !== true) {
  toast.warning('Debes tener una postulación aceptada para ver los datos del paciente');
  return;
}

// Navigate to patient ficha
navigate(`/moduloAspirante/ficha-paciente/${idPaciente}`);
```
