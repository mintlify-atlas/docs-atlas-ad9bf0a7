## Overview

The CALMA API is a RESTful service that powers the geriatric care platform, enabling connections between caregivers (aspirantes), contractors (contratantes), and patients (pacientes).

## Base URL

All API requests should be made to:

```
http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090
```

<Warning>
  The current API uses HTTP. For production deployment, ensure HTTPS is configured for secure communication.
</Warning>

## Common Patterns

### Request Format

Most endpoints accept JSON payloads:

```javascript
const response = await axios.post(
  'http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/resource',
  {
    field1: 'value1',
    field2: 'value2'
  },
  {
    headers: {
      'Content-Type': 'application/json'
    }
  }
);
```

### Response Format

Successful responses typically return JSON with the requested data:

```json
{
  "id": 123,
  "field1": "value1",
  "field2": "value2",
  "createdAt": "2024-03-15T10:30:00Z"
}
```

### Error Handling

Errors return appropriate HTTP status codes with error messages:

```json
{
  "success": false,
  "message": "Error description",
  "code": "ERROR_CODE"
}
```

Common status codes:

| Status | Meaning |
|--------|----------|
| 200 | Success |
| 201 | Created |
| 400 | Bad Request |
| 401 | Unauthorized |
| 404 | Not Found |
| 500 | Server Error |

## Service Layer Pattern

The frontend uses service modules to encapsulate API calls:

```javascript
// servicios/resourceService.js
import axios from 'axios';

const API_URL = 'http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/resource';

export const getResources = async () => {
  try {
    const response = await axios.get(API_URL);
    return response.data;
  } catch (error) {
    throw new Error('Error al obtener recursos: ' + error.message);
  }
};

export const getResourceById = async (id) => {
  try {
    const response = await axios.get(`${API_URL}/${id}`);
    return response.data;
  } catch (error) {
    throw new Error('Error al obtener recurso: ' + error.message);
  }
};

export const createResource = async (data) => {
  try {
    const response = await axios.post(API_URL, data);
    return response.data;
  } catch (error) {
    throw new Error('Error al crear recurso: ' + error.message);
  }
};
```

## Axios Configuration

Some services include global interceptors for error handling:

```javascript
import axios from 'axios';

axios.interceptors.response.use(
  response => response,
  error => {
    console.error('Error en la respuesta:', error);
    return Promise.reject(error);
  }
);
```

## Date Handling

Dates are typically ISO 8601 strings:

```json
{
  "fecha_registro": "2024-03-15T10:30:00.000Z",
  "fecha_limite": "2024-04-01"
}
```

Frontend formatting:

```javascript
// Parse and format dates
const formatDate = (isoString) => {
  return new Date(isoString).toLocaleDateString('es-ES', {
    year: 'numeric',
    month: 'long',
    day: 'numeric'
  });
};

// Remove time from ISO string
const dateOnly = isoString.split('T')[0];
```
