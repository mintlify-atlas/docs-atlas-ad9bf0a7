## Overview

The Jobs API manages employment opportunities (trabajos/empleos) posted by contractors. The system uses two main endpoints: `/api/generar` for job publications and `/api/publicacion_empleo` for job management.

## Base URLs

```
http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/generar
http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/publicacion_empleo
```

### Response Processing

The frontend transforms the response into a cleaner format:

```javascript
const trabajosData = res.data.map(item => {
  const parroquia = item.publicacionempleo?.parroquia;
  const canton = parroquia?.canton;
  const provincia = canton?.provincia;

  return {
    id: item.publicacionempleo?.id_postulacion_empleo,
    titulo: item.publicacionempleo?.titulo || 'Sin título',
    descripcion: item.publicacionempleo?.descripcion || 'Sin descripción',
    salario: item.publicacionempleo?.salario_estimado || 0,
    fechaLimite: item.publicacionempleo?.fecha_limite?.split('T')[0] || null,
    contratante: item.contratante?.usuario?.nombres || 'Anónimo',
    empresa: item.contratante?.empresas?.[0]?.nombreEmpresa || null,
    fechaPublicacion: item.fechaPublicacion?.split('T')[0] || 'Sin fecha',
    requisitos: item.publicacionempleo?.requisitos || 'No especificado',
    jornada: item.publicacionempleo?.jornada || 'No especificada',
    correo: item.contratante?.usuario?.correo || null,
    turno: item.publicacionempleo?.turno || 'No especificado',
    disponibilidad: item.publicacionempleo?.disponibilidad_inmediata === true 
      ? 'Inmediata' : 'No Inmediata',
    actividadesRealizar: item.publicacionempleo?.actividades_realizar || 'No especificadas',
    ubicacion: {
      parroquia: parroquia?.nombre || '',
      canton: canton?.nombre || '',
      provincia: provincia?.nombre || ''
    }
  };
});
```

## Delete Job Posting

### DELETE /api/publicacion_empleo/eliminar/{idPublicacion}

Delete a job posting by its ID.

**Location:** Used in **source/src/components/ModuloContratante/ListaPublicaciones/listaPublicaciones.jsx:70**

```javascript
const response = await axios.delete(
  `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/publicacion_empleo/eliminar/${idPublicacion}`
);

const mensaje = response.data; // Success/error message string
```

### Response Handling

The endpoint returns a text message indicating success or failure:

```javascript
const mensaje = response.data.toLowerCase();

if (mensaje.includes('correctamente')) {
  // Deletion successful
  toast.success(response.data);
} else if (mensaje.includes('no se puede') || mensaje.includes('error') || mensaje.includes('no encontrada')) {
  // Deletion failed
  toast.error(response.data);
} else {
  toast.info(response.data);
}
```

Common responses:
- "Publicación eliminada correctamente"
- "No se puede eliminar la publicación porque tiene postulaciones activas"
- "Publicación no encontrada"

## Usage Examples

### List Contractor's Jobs

```javascript
import { useState, useEffect } from 'react';
import axios from 'axios';

const MisPublicaciones = ({ userId }) => {
  const [publicaciones, setPublicaciones] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchPublicaciones = async () => {
      try {
        const res = await axios.get(
          `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/generar/contratante/${userId}`
        );
        setPublicaciones(res.data);
      } catch (err) {
        console.error('Error al cargar publicaciones:', err);
      } finally {
        setLoading(false);
      }
    };

    fetchPublicaciones();
  }, [userId]);

  return (
    <div>
      {publicaciones.map(pub => (
        <div key={pub.id_genera}>
          <h3>{pub.publicacionempleo.titulo}</h3>
          <p>Salario: ${pub.publicacionempleo.salario_estimado}</p>
          <p>Fecha límite: {pub.publicacionempleo.fecha_limite}</p>
        </div>
      ))}
    </div>
  );
};
```

### Show Available Jobs

```javascript
const TrabajosDisponibles = ({ idAspirante }) => {
  const [trabajos, setTrabajos] = useState([]);

  useEffect(() => {
    const fetchTrabajos = async () => {
      try {
        const res = await axios.get(
          `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/generar/publicaciones-no-postuladas/${idAspirante}`
        );
        
        const trabajosFormateados = res.data.map(item => ({
          id: item.publicacionempleo.id_postulacion_empleo,
          titulo: item.publicacionempleo.titulo,
          salario: item.publicacionempleo.salario_estimado,
          ubicacion: `${item.publicacionempleo.parroquia.nombre}, ${item.publicacionempleo.parroquia.canton.nombre}`,
          fechaLimite: item.publicacionempleo.fecha_limite.split('T')[0]
        }));
        
        setTrabajos(trabajosFormateados);
      } catch (err) {
        console.error('Error cargando trabajos:', err);
      }
    };

    fetchTrabajos();
  }, [idAspirante]);

  return (
    <div>
      {trabajos.map(trabajo => (
        <JobCard key={trabajo.id} trabajo={trabajo} />
      ))}
    </div>
  );
};
```

### Delete Job with Confirmation

```javascript
import { toast } from 'react-toastify';

const deleteJob = async (idPublicacion) => {
  if (!window.confirm('¿Estás seguro de eliminar esta publicación?')) {
    return;
  }

  try {
    const response = await axios.delete(
      `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/publicacion_empleo/eliminar/${idPublicacion}`
    );
    
    const mensaje = response.data.toLowerCase();
    
    if (mensaje.includes('correctamente')) {
      toast.success('Publicación eliminada exitosamente');
      // Refresh the list
      fetchPublicaciones();
    } else {
      toast.error(response.data);
    }
  } catch (error) {
    console.error('Error eliminando publicación:', error);
    toast.error('No se pudo eliminar la publicación');
  }
};
```

## Filtering and Search

Frontend typically implements client-side filtering:

```javascript
const [filtroTitulo, setFiltroTitulo] = useState('');
const [filtroFecha, setFiltroFecha] = useState('');
const [rangoSalario, setRangoSalario] = useState([0, 9999999]);

const trabajosFiltrados = trabajos.filter(trabajo => {
  const tituloMatch = trabajo.titulo
    .toLowerCase()
    .includes(filtroTitulo.toLowerCase());
  
  const fechaMatch = filtroFecha
    ? trabajo.fechaPublicacion === filtroFecha
    : true;
  
  const salario = trabajo.salario || 0;
  const [min, max] = rangoSalario;
  const salarioMatch = salario >= min && salario <= max;
  
  return tituloMatch && fechaMatch && salarioMatch;
});
```
