## Overview

The Applications API (postulaciones) manages job applications from caregivers (aspirantes) to job postings. The system tracks application status, application dates, and allows contractors to accept or reject applications.

## Base URL

```
http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/realizar
```

## Submit Application

### POST /api/realizar/postular

Submit a job application from an aspirante to a specific job posting.

**Location:** Used in **source/src/components/ModuloAspirante/CardTrabajo/cardTrabajo.jsx:50**

<CodeGroup>
```javascript Fetch API
const response = await fetch(
  `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/realizar/postular?idAspirante=${idAspirante}&idPublicacionEmpleo=${idPublicacionEmpleo}`,
  { method: 'POST' }
);

if (response.ok) {
  console.log('Postulación exitosa');
} else if (response.status === 409) {
  console.log('Ya te has postulado a esta oferta');
} else {
  const error = await response.text();
  console.error('Error al postular:', error);
}
```

```bash cURL
curl -X POST 'http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/realizar/postular?idAspirante=15&idPublicacionEmpleo=42'
```
</CodeGroup>

### Query Parameters

<ParamField query="idAspirante" type="number" required>
  ID of the caregiver applying for the job
</ParamField>

<ParamField query="idPublicacionEmpleo" type="number" required>
  ID of the job posting to apply to
</ParamField>

### Response Status Codes

| Status | Meaning |
|--------|----------|
| 200 | Application submitted successfully |
| 409 | Already applied (duplicate application) |
| 400 | Invalid parameters |
| 500 | Server error |

## Processing Application Data

The frontend extracts relevant information from the nested structure:

```javascript
postulaciones.map((postulacion) => {
  const empleo = postulacion.postulacion.postulacion_empleo;
  const estado = postulacion.postulacion.estado;
  const idPaciente = empleo.id_paciente;
  
  return {
    id: postulacion.id_realizar,
    fechaPostulacion: postulacion.fecha,
    titulo: empleo.titulo,
    descripcion: empleo.descripcion,
    salario: empleo.salario_estimado,
    contratante: empleo.contratante?.nombre,
    ubicacion: empleo.parroquia?.nombre,
    estado: estado === null ? 'Pendiente' : estado ? 'Aceptada' : 'Rechazada',
    idPaciente: idPaciente
  };
});
```

## Application States

<Tabs>
  <Tab title="Pending">
    **estado = null**
    
    - Application submitted but not yet reviewed
    - Default state when application is created
    - Displayed with hourglass icon (⏳)
    - Color: Yellow/Orange
    
    ```javascript
    if (estado === null) {
      return { status: 'Pendiente', icon: <FaHourglassHalf /> };
    }
    ```
  </Tab>
  
  <Tab title="Accepted">
    **estado = true**
    
    - Application approved by contractor
    - Caregiver can view patient details
    - Displayed with check icon (✓)
    - Color: Green
    
    ```javascript
    if (estado === true) {
      return { status: 'Aceptada', icon: <FaCheckCircle /> };
    }
    ```
    
    **Available Actions:**
    - View patient data
    - Contact contractor
    - Access patient ficha
  </Tab>
  
  <Tab title="Rejected">
    **estado = false**
    
    - Application declined by contractor
    - No further action available
    - Displayed with X icon (✗)
    - Color: Red
    
    ```javascript
    if (estado === false) {
      return { status: 'Rechazada', icon: <FaTimesCircle /> };
    }
    ```
  </Tab>

## Usage Examples

### Submit Application

```javascript
const handleAplicar = async (idAspirante, idPublicacionEmpleo) => {
  if (!idAspirante) {
    toast.error('No se pudo obtener el ID del aspirante');
    return;
  }

  try {
    const response = await fetch(
      `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/realizar/postular?idAspirante=${idAspirante}&idPublicacionEmpleo=${idPublicacionEmpleo}`,
      { method: 'POST' }
    );

    if (response.ok) {
      toast.success('Postulación exitosa');
      setPostulado(true);
    } else if (response.status === 409) {
      toast.warning('Ya te has postulado a esta oferta');
      setPostulado(true);
    } else {
      const errorText = await response.text();
      toast.error(`Error al postular: ${errorText}`);
    }
  } catch (error) {
    console.error('Error inesperado al postular:', error);
    toast.error('Error inesperado al postular');
  }
};
```

### Display User's Applications

```javascript
import { useState, useEffect } from 'react';
import axios from 'axios';

const MisPostulaciones = ({ aspiranteId }) => {
  const [postulaciones, setPostulaciones] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchPostulaciones = async () => {
      try {
        const response = await axios.get(
          `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/realizar/aspirante/${aspiranteId}`
        );
        setPostulaciones(response.data);
      } catch (error) {
        console.error('Error al cargar postulaciones:', error);
      } finally {
        setLoading(false);
      }
    };

    fetchPostulaciones();
  }, [aspiranteId]);

  const getEstadoLabel = (estado) => {
    if (estado === null) return 'Pendiente';
    return estado ? 'Aceptada' : 'Rechazada';
  };

  return (
    <div>
      {postulaciones.map((post) => {
        const empleo = post.postulacion.postulacion_empleo;
        const estado = post.postulacion.estado;
        
        return (
          <div key={post.id_realizar}>
            <h3>{empleo.titulo}</h3>
            <p>Estado: {getEstadoLabel(estado)}</p>
            <p>Fecha: {new Date(post.fecha).toLocaleDateString()}</p>
            <p>Salario: ${empleo.salario_estimado}</p>
          </div>
        );
      })}
    </div>
  );
};
```

### Filter Applications by Status

```javascript
const filterPostulaciones = (postulaciones, filterType) => {
  return postulaciones.filter(post => {
    const estado = post.postulacion.estado;
    
    switch (filterType) {
      case 'pending':
        return estado === null;
      case 'accepted':
        return estado === true;
      case 'rejected':
        return estado === false;
      default:
        return true;
    }
  });
};

// Usage
const pendientes = filterPostulaciones(postulaciones, 'pending');
const aceptadas = filterPostulaciones(postulaciones, 'accepted');
const rechazadas = filterPostulaciones(postulaciones, 'rejected');
```

## Date Formatting

Applications include timestamp formatting:

```javascript
const formatoFecha = (fecha) => {
  if (!fecha) return 'Fecha no disponible';

  try {
    const options = {
      year: 'numeric',
      month: 'long',
      day: 'numeric'
    };
    return new Date(fecha).toLocaleDateString('es-ES', options);
  } catch {
    return 'Fecha inválida';
  }
};

// Output: "15 de marzo de 2024"
```

<Info>
  **Application Workflow:**
  1. Aspirante browses available jobs (not yet applied)
  2. Submits application via POST `/api/realizar/postular`
  3. Application starts with `estado = null` (pending)
  4. Contractor reviews and updates estado to true/false
  5. If accepted, aspirante can access patient details
</Info>

<Warning>
  Duplicate applications return a 409 status code. Handle this gracefully in the UI to inform users they've already applied.
</Warning>
