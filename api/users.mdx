## Overview

The Users API manages user accounts, profiles, and registration for all user types (aspirantes, contratantes, and patients).

## Base URL

```
http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/usuarios
```

## Get User by ID

### GET /api/usuarios/{id}

Retrieve a specific user by their ID.

```javascript
import axios from 'axios';

const response = await axios.get(
  `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/usuarios/${userId}`
);

const user = response.data;
```

## Registration Endpoints

### Register Aspirante (Caregiver)

**POST /api/registro/aspirante**

**Service:** `source/src/servicios/registrarService.js:12`

<CodeGroup>
```javascript Service Implementation
import axios from 'axios';

export const registrarAspirante = async (payload) => {
  try {
    const dataToSend = {
      ...payload,
      aspiracionSalarial: payload.aspiracionSalarial !== undefined ?
        Number(payload.aspiracionSalarial) : null
    };
    
    const response = await axios.post(
      'http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/registro/aspirante',

    console.error('Error al registrar aspirante:', error);

};
```

## User Roles

The system defines three primary user roles:

<Tabs>
  <Tab title="ASPIRANTE">
    **Caregiver/Applicant**
    
    Database fields:
    - `idAspirante` - Unique aspirante ID
    - `aspiracionSalarial` - Expected salary
    - `experiencia` - Work experience description
    - `disponibilidad` - Availability status
    - `usuario` - Reference to user record
    
    Endpoints:
    - POST `/api/registro/aspirante`
    - GET `/api/registro/aspirante/detalle/{id}`
    - GET `/api/usuarios/buscar_aspirante/{id}`
  </Tab>
  
  <Tab title="CONTRATANTE">
    **Contractor/Employer**
    
    Database fields:
    - `idContratante` - Unique contractor ID
    - `direccion` - Business address
    - `empresa` - Company name
    - `usuario` - Reference to user record
    
    Endpoints:
    - POST `/api/registro/contratante`
    - GET `/api/usuarios/buscar_contratante/{id}`
  </Tab>
  
  <Tab title="PACIENTE">
    **Patient**
    
    Database fields:
    - `id_paciente` - Unique patient ID
    - `fecha_nacimiento` - Birth date
    - `genero` - Gender
    - `usuario` - Reference to user record
    
    Endpoints:
    - POST `/api/registro/paciente`
    - GET `/api/pacientes/{id}`
  </Tab>
</Tabs>

## Usage Examples

### Check if User Exists by Email

```javascript
const checkUserExists = async (email) => {
  try {
    const response = await fetch(
      `http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/usuarios/por-correo?correo=${email}`
    );
    
    if (response.ok) {
      const user = await response.json();
      return user !== null;
    }
    return false;
  } catch (error) {
    console.error('Error checking user:', error);
    return false;
  }
};
```

### Get User from LocalStorage

```javascript
const getUserData = () => {
  const userData = JSON.parse(localStorage.getItem('userData') || '{}');
  return {

};
```

## Error Handling

```javascript
try {
  const response = await axios.get(`/api/usuarios/${userId}`);
  return response.data;
} catch (error) {
  if (error.response) {
    // Server responded with error status
    if (error.response.status === 404) {
      throw new Error('Usuario no encontrado');
    } else if (error.response.status === 500) {
      throw new Error('Error del servidor');
    }
  } else if (error.request) {
    // Request made but no response
    throw new Error('No se pudo conectar con el servidor');
  } else {
    // Other errors
    throw new Error('Error inesperado: ' + error.message);
  }
}
```
