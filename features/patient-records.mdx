## Overview

The Ficha (Patient Record) system is a comprehensive healthcare management module that stores detailed patient information including medical diagnoses, daily routines, medications, allergies, interests, and conversation topics.

### Validation Rules

The component implements comprehensive validation at **source/src/components/FichaPaciente/ficha.jsx:199**:

<Steps>
  <Step title="Medical Information">
    - Diagnosis: minimum 5 characters, medical text format
    - Physical conditions: minimum 3 characters
    - Mood state: required selection from predefined options
  </Step>
  
  <Step title="Communication">
    - If communication difficulties checked, description is required (min 3 chars)
    - Falls risk: required selection (alta/media/baja)
  </Step>
  
  <Step title="Diet and Routines">
    - Diet type: required selection
    - Wake/sleep times: must have at least 1 hour difference
    - Nap and bath frequency: required, allows numbers
  </Step>
  
  <Step title="Medical Care">
    - Medical routine: required, medical text format
    - Observations: minimum 5 characters
    - Registration date: cannot be in the future
  </Step>
</Steps>

```javascript
const API_URL = 'http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090/api/alergias';

// List all allergies
export const getAlergias = async () => {
  const response = await axios.get(`${API_URL}/listar`);
  return response.data;
};

// Get specific allergy
export const getAlergiaById = async (id) => {
  const response = await axios.get(`${API_URL}/listar/${id}`);
  return response.data;
};

// Create new allergy
export const createAlergia = async (alergia) => {
  const response = await axios.post(`${API_URL}/crear`, alergia);
  return response.data;
};

// Update allergy
export const updateAlergia = async (id, alergia) => {
  const response = await axios.put(`${API_URL}/actualizar/${id}`, alergia);
  return response.data;
};

// Delete allergy
export const deleteAlergia = async (id) => {
  await axios.delete(`${API_URL}/eliminar/${id}`);
};
```

### Allergy Types

The system supports two types of allergies:

1. **Food Allergies** (alergiaali.jsx) - Managed via `/api/alergias` endpoints
2. **Medication Allergies** (alergiamedicamento.jsx) - Similar structure for drug allergies

## Multi-Step Navigation

The ficha system uses a step-by-step navigation component at **source/src/components/FichaPaciente/fichastepsNav.jsx:1**:

```
1. Ficha (Basic Information)
2. Medicamentos (Medications)
3. Alergias (Allergies)
4. Intereses (Interests)
5. Temas (Conversation Topics)
```

After creating or updating the main ficha, users are redirected:

```javascript
navigate(`/fichas/${id_ficha_paciente}/medicamentos`);
```
