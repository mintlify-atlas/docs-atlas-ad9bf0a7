## Overview

CALMA's CV management system enables healthcare professionals to create detailed, professional CVs that showcase their experience, education, skills, and qualifications. The system is built around the CVForm component and includes multiple sub-components for certificates, recommendations, skills, and availability.

## CV Form Component

The main CV form is located at `src/components/ModuloAspirante/CV/cv.jsx` and provides a comprehensive interface for building a professional profile.

## CV Protection

CALMA requires users to complete their CV before accessing certain features through the `RequireCV` component:

```javascript RequireCV.jsx
import { Navigate } from 'react-router-dom';

function RequireCV({ children }) {
  const cvCompleto = localStorage.getItem('cvCompleto');
  
  if (!cvCompleto) {
    return <Navigate to="/moduloAspirante/cv" replace />;
  }
  
  return children;
}
```

### Protected Routes

Routes that require a complete CV:
- Job applications
- Postulations management
- Profile access
- Certificate management
- Recommendations

## Technical Implementation

### Form Validation

The CV form includes comprehensive validation:

```javascript
// Email validation
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

// Phone validation
const phoneRegex = /^[0-9]{10}$/;

// Required field validation
if (!formData.nombres || !formData.apellidos || !formData.cedula) {
  toast.error('Por favor completa todos los campos obligatorios');
  return;
}
```

### State Management

CV data is managed using React hooks:

```javascript
const [formData, setFormData] = useState({
  nombres: '',
  apellidos: '',
  titulo: '',
  // ... other fields
});

const handleChange = (e) => {
  const { name, value } = e.target;
  setFormData(prev => ({
    ...prev,
    [name]: value
  }));
};
```

### API Service

CV operations use the axios-based service:

```javascript cvService.js
import axios from 'axios';

const API_BASE = 'http://backend-alb-283290471.us-east-2.elb.amazonaws.com:8090';

export const cvService = {
  getCV: (id) => axios.get(`${API_BASE}/api/cv/${id}`),
  createCV: (data) => axios.post(`${API_BASE}/api/cv`, data),
  updateCV: (id, data) => axios.put(`${API_BASE}/api/cv/${id}`, data),
  deleteCV: (id) => axios.delete(`${API_BASE}/api/cv/${id}`)
};
```
