## Overview

CALMA implements a WebRTC-based video calling system using STOMP over WebSockets for signaling. The system enables real-time video communication between caregivers and patients/contractors.

const servers = {

### Call Flow

#### Initiator (Emisor)

```javascript
function iniciarLlamada() {
  peerConnection = new RTCPeerConnection(servers);
  
  // Add local stream
  localStream.getTracks().forEach(track => {
    peerConnection.addTrack(track, localStream);
  });
  
  // Handle remote stream
  peerConnection.ontrack = (event) => {
    remoteVideo.srcObject = event.streams[0];
  };
  
  // Handle ICE candidates
  peerConnection.onicecandidate = (event) => {
    if (event.candidate) {
      enviarSeñal({
        tipo: "ice",
        candidato: event.candidate
      });
    }
  };
  
  // Create and send offer
  peerConnection.createOffer()
    .then((oferta) => peerConnection.setLocalDescription(oferta))
    .then(() => {
      enviarSeñal({
        tipo: "oferta",
        descripcion: peerConnection.localDescription
      });
    });
}
```

#### Signal Handling

```javascript
function manejarSeñal(data) {
  if (data.tipo === "oferta") {
    // Receiver handles offer and creates answer
    peerConnection.setRemoteDescription(new RTCSessionDescription(data.descripcion))
      .then(() => peerConnection.createAnswer())
      .then((respuesta) => peerConnection.setLocalDescription(respuesta))
      .then(() => {
        enviarSeñal({
          tipo: "respuesta",
          descripcion: peerConnection.localDescription
        });
      });
  } else if (data.tipo === "respuesta") {
    // Initiator handles answer
    peerConnection.setRemoteDescription(new RTCSessionDescription(data.descripcion));
  } else if (data.tipo === "ice" && data.candidato) {
    // Both parties handle ICE candidates
    peerConnection.addIceCandidate(new RTCIceCandidate(data.candidato));
  }
}
```

### Sending Signals

Signals are sent via STOMP to the WebSocket endpoint:

```javascript
function enviarSeñal(mensaje) {
  stompClient.send(
    `/app/llamada/${receptor}`,
    {},
    JSON.stringify(mensaje)
  );
}
```

## Ending a Call

The call can be terminated by clicking the hang-up button:

```javascript
document.getElementById("colgarBtn").addEventListener("click", () => {
  if (peerConnection) peerConnection.close();
  localStream.getTracks().forEach(track => track.stop());
  window.close();
});
```

## Usage Example

To initiate a call from user A (ID: 123) to user B (ID: 456):

**User A (Initiator):**
```
/videollamada.html?emisor=123&receptor=456&soyElEmisor=true
```

**User B (Receiver):**
```
/videollamada.html?emisor=123&receptor=456&soyElEmisor=false
```

## Technical Notes

<Info>
  - The local video is muted to prevent audio feedback
  - ICE candidates are continuously exchanged during connection establishment
  - The system requires HTTPS for camera/microphone access in production
  - STUN server is used for NAT traversal; TURN server may be needed for restrictive networks
</Info>

<Warning>
  The current implementation uses HTTP. For production, ensure:
  - Use HTTPS for secure connections
  - Implement proper authentication
  - Consider adding TURN servers for firewall traversal
  - Add error handling for connection failures
</Warning>

## Connection States

The `estado` element displays connection status:

- **"Cámara activa"** - Camera initialized successfully
- **"Conectado a STOMP"** - WebSocket connection established
- **"Error al acceder a la cámara"** - Camera permission denied
