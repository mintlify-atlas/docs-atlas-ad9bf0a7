## Overview

The job posting system in CALMA enables employers (Contratantes) to create, publish, and manage job opportunities. The system includes comprehensive form fields, location-based filtering, and application management.

## Location Cascade

The location selection uses a three-level cascade:

```javascript
// Province → Canton → Parish cascade
const [provincias, setProvincias] = useState([]);
const [cantones, setCantones] = useState([]);
const [parroquias, setParroquias] = useState([]);

// Load cantones when province changes
useEffect(() => {
  if (selectedProvincia) {
    axios.get(`${API_URL}/api/cantones/provincia/${selectedProvincia}`)
      .then(res => setCantones(res.data));
  }
}, [selectedProvincia]);

// Load parroquias when canton changes
useEffect(() => {
  if (selectedCanton) {
    axios.get(`${API_URL}/api/parroquias/canton/${selectedCanton}`)
      .then(res => setParroquias(res.data));
  }
}, [selectedCanton]);
```

## Validation

The form includes client-side validation:

```javascript
// Validation checks
const validateForm = () => {
  if (!titulo || titulo.trim().length < 5) {
    toast.error('El título debe tener al menos 5 caracteres');
    return false;
  }
  
  if (!descripcion || descripcion.trim().length < 20) {
    toast.error('La descripción debe tener al menos 20 caracteres');
    return false;
  }
  
  if (!salario || salario <= 0) {
    toast.error('Ingresa un salario válido');
    return false;
  }
  
  if (!id_provincia || !id_canton) {
    toast.error('Selecciona la ubicación completa');
    return false;
  }
  
  return true;
};
```

## Best Practices

<AccordionGroup>
  <Accordion title="Write clear job titles">
    Use specific, searchable titles like "Enfermera de Cuidados Intensivos" rather than vague titles like "Personal de Salud".
  </Accordion>
  
  <Accordion title="Detailed descriptions">
    Include day-to-day responsibilities, work environment, team structure, and growth opportunities.
  </Accordion>
  
  <Accordion title="Realistic requirements">
    Only list essential requirements. Avoid creating barriers with unnecessary qualifications.
  </Accordion>
  
  <Accordion title="Fair compensation">
    Offer competitive salaries based on market rates for the position and location.
  </Accordion>
  
  <Accordion title="Set reasonable deadlines">
    Give candidates enough time to prepare applications (at least 1-2 weeks).
  </Accordion>
  
  <Accordion title="Respond promptly">
    Review applications quickly and provide feedback to candidates.
  </Accordion>
</AccordionGroup>

<Note>
  Job postings with complete information and competitive compensation receive 3x more qualified applications.
</Note>

<Warning>
  Ensure all job information complies with labor laws and regulations in Ecuador.
</Warning>
